# Olympiad Finder
> Мобильное приложение для поиска олимпиад школьников, которое я написал в 16 лет (май 2024 года)

## О проекте
Я учился в IT школе Samsung, нужно было выбрать тему для итогового проекта. Будучи 'олимпиадником', я подумал что можно сделать что-то классное с олимпиадками. Мне надоело мониторить кучу страниц чтобы узнать даты этапов, предметы и подходящие классы. Так я решил сделать Olympiad Finder - карманный агрегатор олимпиад с фильтрами.

У сайта https://olimpiada.ru не было открытого API (честно не знаю, есть ли сейчас), поэтому данные собираются парсером на лету при первом запуске приложения и сохраняются в локальную базу данных. 

## Возможности

- Поиск и фильтры
  - По ключевым словам, названиям и предметам
  - Мульти фильтр по классам участия (1-11 класс)
- Разбиение предметов на категории
  - Олимпиады тегируются на технические, гуманитарные, естественнонаучные и спортивные
> И для каждого типа олимпиады своя картиночка :) [тут фото надо]
- Расписание этапов
  - Раскрывающий список дат и этапов олимпиад
- Избранное
  - Можно сохранить олимпиаду в отдельный список (привязывается по конкретному id олимпиады, [переживает ли снос базы?])
- Ссылки
   - Можно сразу перейти на страницу на olimpiada.ru или на сайт самой олимпиады, если есть
- Оффлайн режим
  - После первого парсинга приложение может работать оффлайн. При желании можно обновить данные
